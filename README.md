# CSVILKA

Серверный античит для Counter-Strike 2 (C++, Metamod:Source 2.0 сборка 1461 и новее, Windows x64 / Linux x64).

CSVILKA анализирует прицеливание, выстрелы, движение, нажатия кнопок и клиентские настройки, которые игроки отправляют серверу. Игрокам ничего устанавливать не нужно.

## Главное отличие: защита от ложных банов

Статистический детект (аим, движение, тайминги) сам по себе **не банит**. Бан отправляется только когда:

- набралось `csvilka_ban_confirmations` (по умолчанию **2**) очков улик от независимых детектов,
- между детектами минимум 30 секунд (одна серия выстрелов не считается дважды),
- все они попали в окно `csvilka_confirmation_window` (по умолчанию **1800 с**); история хранится по SteamID64 и не сбрасывается ни переподключением, ни сменой карты.

Слабые эвристические детекты (`IRREGULAR BEHAVIOR`, `INHUMAN ACCURACY`, `TRIGGERBOT`, `DOUBLETAP`, `AUTOSTRAFE`, `HYPERSCROLL`) дают 0,5 очка и не могут привести к бану без хотя бы одного сильного детекта (принцип «ни один сигнал не осуждает в одиночку»).

Сразу банят только детерминированные проверки, где ошибка исключена: `DLL INJECTION`, `INVALID CVAR`, `INVALID INPUT`.

Дополнительно:

- **Неподтверждённые детекты не объявляются в чате.** Пока улик не хватает для бана (а также во время разминки, при плохой сети и в режиме наблюдения), детект видят только администраторы: консоль, журнал и Discord. Так честный игрок не получит публичного обвинения из-за случайного срабатывания. Включить объявления: `csvilka_announce_unconfirmed 1`.
- `csvilka_observe_mode 1` — только детект и отчёты, без наказаний. Рекомендуется на первые дни на новом сервере.
- `csvilka_ignore_warmup 1` — во время разминки статистические детекты не наказываются.
- Сетевое вето: при высоком пинге, джиттере, потере пакетов или choke наказание не отправляется.
- `DESUBTICKING`, `NULLS`, `SUBTICK SPAM` дают только кик.
- `csvilka_whitelist` — игроки детектятся, но никогда не наказываются.
- Автообновление выключено по умолчанию.

## Новые детекты (экспериментальные)

Эти детекты появились в версиях 1.1.0 и 1.2.0 и ещё не проверены на реальных серверах. Поэтому по умолчанию (`csvilka_experimental_enforce 0`) они **только сообщают администраторам** (консоль, журнал, Discord): ничего не объявляют в чате, не дают очков улик и никого не наказывают. Когда убедитесь по журналу, что они не срабатывают на честных игроков, поставьте `csvilka_experimental_enforce 1` — тогда они будут объявляться и давать 0,5 очка (как слабые детекты, без сильного детекта бана не будет).

| Детект | Что ищет | Как работает |
|---|---|---|
| `RECOIL` | Скрипт компенсации отдачи (RCS, no-recoil) | Для каждой пули считается, куда она реально ушла: углы прицела + отдача × `weapon_recoil_scale`. Человек тянет мышь вниз по общей траектории, но не может погасить каждый отдельный «зигзаг» отдачи; скрипт гасит их точно. Срабатывает, если в 3 очередях (от 12 пуль) за 10 минут осталось не больше 10 % зигзага. В моделировании у человека, который реагирует на отдачу, остаётся больше 60 %, и даже идеально заученная наизусть очередь с дрожанием руки всего 0,04° на пулю не опускается до 10 %; у скрипта остаётся 2–10 %. |
| `WALLHACK` | Убийства врагов, которых игрок не видел | Сервер отмечает, кого каждый игрок «заметил» своим обзором (та же система, что радар). Срабатывает, если за 15 секунд сделано 4 убийства в голову по 4 разным врагам, которых убийца не замечал предыдущие 30 секунд. Идея и пороги взяты из открытого античита OSAntiCheat (MIT), где на 321 тыс. убийств такое случилось 2 раза — оба раза у читеров. Не работает в режимах с возрождением и «все против всех». |
| `ESP` | ВХ, пойманный приманками CS2GLAZ | Приходит из плагина [CS2GLAZ](https://github.com/glazki2/cs2antiwh), если он стоит на сервере (см. «Связка с CS2GLAZ»). Его приманки — невидимые фальшивые враги за стенами, которых честный игрок увидеть не может; контрольные приманки не получает ни один клиент. Детект приходит каждый раз, когда «улика» игрока (отметки по настоящим приманкам сверх того, что могло набраться случайно, с запасом в три стандартных отклонения) вырастает на целое число. С `csvilka_esp_strong 1` (и `csvilka_experimental_enforce 1`) считается сильным детектом — 1 очко. |
| `NOFLASH` | Убранный эффект флешки | Игра помечает убийства, сделанные ослеплённым игроком. Срабатывает на 3 таких убийства разных врагов за 90 секунд, все дальше 400 единиц, из них минимум 2 в голову. |

## Проверка банов Steam (VAC и игровые)

CSVILKA может спрашивать у Steam историю банов каждого вошедшего игрока (официальный Steam Web API, метод `GetPlayerBans`). Это не догадка, а данные самого Valve.

1. Получите ключ Steam Web API: <https://steamcommunity.com/dev/apikey>.
2. Пропишите его в конфиг: `csvilka_steam_api_key "ВАШ_КЛЮЧ"` (32 символа; значение не показывается в консоли).
3. По умолчанию (`csvilka_ban_history_kick_days 0`) игроки с банами только попадают в отчёт для администраторов. Если поставить, например, `365`, игроки, у которых последний VAC- или игровой бан был не больше года назад, будут кикаться командой `csvilka_kick_command`. Игроки из белого списка не кикаются никогда.

Каждый аккаунт проверяется не чаще раза в 12 часов, запросы отправляются пачками до 100 игроков.

## Связка с CS2GLAZ

[CS2GLAZ](https://github.com/glazki2/cs2antiwh) — серверный анти-ВХ: не отправляет игроку врагов, которых тот не видит, и ставит приманки для ВХ. Если на сервере стоят оба плагина, они находят друг друга через Metamod сами, в любом порядке загрузки:

- **CS2GLAZ → CSVILKA.** Улика по приманкам приходит детектом `ESP` (с подробностями в журнале и Discord) и проходит все правила CSVILKA: наблюдение, белый список, сетевое вето, разминку, подтверждение другими детектами и команду бана. По умолчанию `ESP` экспериментальный — только отчёт; с `csvilka_experimental_enforce 1` даёт 0,5 очка, с `csvilka_esp_strong 1` — 1 очко. Выключить приём: `csvilka_esp_enabled 0`.
- **CSVILKA → CS2GLAZ.** Любой детект CSVILKA (даже неподтверждённый или только отчёт) и найденная история банов Steam ставят игрока под наблюдение CS2GLAZ на `csvilka_confirmation_window` секунд: его приманки ставятся первыми, а в режиме `cs2glaz_decoys 3` приманки получают только такие игроки. Так подозрительный по аиму игрок быстрее проверяется на ВХ, и вместе два слабых сигнала дают бан там, где каждый по отдельности его бы не дал.
- **Белый список** `csvilka_whitelist` действует и на кик CS2GLAZ по приманкам.
- `csvilka_status` показывает связь (`CS2GLAZ bridge: …`), `csvilka_evidence <steamid64>` — и улику приманок.

Без CS2GLAZ CSVILKA работает как раньше.

## Журнал и команды администратора

- `csvilka_detection_log 1` — каждый детект пишется в `addons/csvilka/logs/detections-ГГГГ-ММ-ДД.log`: время, SteamID64, ник, детект, итог, улики. Итог `report-only` — экспериментальный детект или история банов, `awaiting-confirmation` — ждёт подтверждения.
- `csvilka_detection_command` — команда на каждый детект, даже без наказания (например, запись демо или уведомление админам).
- `csvilka_status` — состояние плагина, защиты от ложных банов и проверки банов Steam.
- `csvilka_evidence [steamid64]` — показать накопленные подтверждения.
- `csvilka_pardon <steamid64>` — сбросить подтверждения игрока (если детект оказался ложным).
- `csvilka_<модуль>_debug 1` — подробный вывод модуля в консоль. Например, `csvilka_recoil_debug 1` показывает, какой процент отдачи остался в каждой очереди.

## Модули

| Группа | Детекты |
|---|---|
| Аим и точность | AIMBOT, AIMLOCK, SILENTAIM, TRIGGERBOT, INHUMAN ACCURACY, IRREGULAR BEHAVIOR, DOUBLETAP, RECOIL* |
| Информация | WALLHACK*, NOFLASH*, ESP* (из CS2GLAZ) |
| Движение | BHOP, HYPERSCROLL, AUTOSTRAFE, NULLS, DESUBTICKING, SUBTICK SPAM |
| Клиент | ANTIAIM, DLL INJECTION, INVALID CVAR, INVALID INPUT, NAMECHANGER |
| Аккаунт | BAN HISTORY (история банов Steam) |

\* экспериментальные, см. выше.

Каждый модуль включается/выключается в `cfg/csvilka.cfg` (`csvilka_<модуль>_enabled`) и имеет debug-режим (`csvilka_<модуль>_debug`).

## Установка

1. Установите Metamod:Source 2.0 (сборка 1461 или новее, интерфейс плагинов 18) на сервер CS2.
2. Распакуйте пакет в корень сервера (пакет начинается с папки `game`).
3. Настройте `game/csgo/cfg/csvilka.cfg`. Язык сообщений по умолчанию — русский (`csvilka_language "ru"`).
4. Запустите сервер, выполните `meta list`, затем `csvilka_status`.

Команды наказания по умолчанию рассчитаны на CS2-SimpleAdmin (`css_addban`, `css_kick`). Для другого админ-плагина замените `csvilka_punishment_command` и `csvilka_kick_command`. Плейсхолдеры: `{steamid64}`, `{userid}`, `{detection}`.

Отчёты в Discord: `csvilka_webhook_url`.

## Сборка

```sh
git clone --recursive https://github.com/glazki2/cs2vilka.git
cd cs2vilka
./build-linux.sh        # Linux, нужен Docker (Steam Runtime 3 SDK)
./build-windows.ps1     # Windows, нужен Visual Studio 2022 + Python 3.8+
```

Готовый пакет появится в `<папка сборки>/package/game`.
